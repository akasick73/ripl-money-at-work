# RIPL Money at Work — Financial GC, contractor-focused version

An Astro static website rebuilt from RIPL Money at Work V5.1 with a mobile-first contractor/trades-owner landing page.

**Deployment details and required placeholder configuration:** see `DEPLOYMENT-SETUP.md`.

`npm ci` then `npm run build`. Upload `dist/` using your normal Cloudflare static-deployment workflow.

**This is a source package, not a tested or deployed production build.** The secure tax portal and booking links are deliberately inactive until you configure them. A compliance review is required before launch.
